# Как выложить Botir в Google Play

1. **Аккаунт разработчика.** Зарегистрируйся в Play Console (play.google.com/console). Взнос — 25 $ один раз.
2. **Ключ подписи.** Добавь в репозиторий на GitHub 4 секрета (Settings → Secrets and variables → Actions):
   `BOTIR_KEYSTORE_B64`, `BOTIR_KS_PASS`, `BOTIR_KEY_ALIAS`, `BOTIR_KEY_PASS` (значения — в файле ключа, который тебе отправил Claude).
   После этого каждая сборка будет подписана твоим ключом. Сам файл ключа в репозиторий не клади.
3. **Создай приложение** в Play Console: название «Botir: Toshkent sarguzashti», тип — игра, бесплатно.
4. **Загрузи `Botir.aab`** из последнего релиза (вкладка Releases репозитория). Включи «Подпись приложений Google Play» — Google хранит итоговый ключ, твой ключ используется только для загрузки.
5. **Описание и графика** — тексты в `store/listing.md`, картинки в `store-graphics.zip`.
6. **Политика конфиденциальности** — ссылка на файл `store/privacy-policy.md` в репозитории.
7. **Анкеты:** рейтинг контента (IARC), целевая аудитория, безопасность данных — ответы в `store/listing.md`.
8. **Закрытое тестирование.** Новые личные аккаунты (созданные после 13.11.2023) должны провести закрытый тест: минимум 12 тестировщиков 14 дней подряд. Только после этого откроется публикация в «Рабочую версию».
9. **Требование к targetSdk.** С 31.08.2026 Google принимает только сборки с targetSdk 36 (Android 16). Проект уже настроен на 36.
10. При каждом обновлении увеличивай `versionCode` в `app/build.gradle.kts`.
