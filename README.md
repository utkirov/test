# Botir — Toshkent sarguzashti

Пиксельный платформер на Kotlin для Android (вертикальный экран, targetSdk 36).

**Глава 1 — Ташкент:** Махалля (батуты, газовые трубы), Чорсу (ломающиеся ящики), Метро (эскалаторы, поезда), Анхор (плавание), Телебашня (ветер, вертикальный подъём), Tashkent City (тросы, босс Жадина-ака).
**Глава 2 — Шёлковый путь:** Самарканд (ритмическая мозаика), Бухара (зыбучий песок, верблюды), Хива (песчаные бури, босс Зикна-ака).

Также: мини-босс на каждом уровне, 63 пасхалки, 3 звезды за уровень, магазин скинов и улучшений, бесконечный режим, сезонные события (Новый год, Навруз, Рамазан), чиптюн-музыка, заставки, настройки (размер кнопок, левша, вибрация), RU/UZ.

## Сборка
Каждый push запускает GitHub Actions: собирает `Botir.apk` и `Botir.aab`, запускает игру в эмуляторе Android (автотест бота по всем уровням + скриншоты для магазина) и публикует всё во вкладке **Releases**.

Локально: открыть папку в Android Studio → Build → Build APK(s).

## Код
- `Game.kt` — физика, механики, прогресс, магазин, эндлесс, рендер мира
- `Levels.kt` — 9 уровней и описание бесконечного режима
- `Mini.kt` — мини-боссы
- `Menu.kt` — все экраны меню и заставки
- `Bg.kt`, `Sprites.kt`, `Skin.kt` — графика
- `Music.kt`, `Sound.kt` — музыка и звуки
- `Season.kt`, `Cut.kt` — сезоны и сценки
- `Tools.kt` — автотест и генерация скриншотов (только для CI)
