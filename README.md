# Botir — Toshkent sarguzashti

Пиксельный платформер на Kotlin для Android (вертикальный экран). 6 локаций Ташкента, у каждой своя механика, 44 пасхалки, босс, языки RU/UZ.

| # | Локация | Механика |
|---|---------|----------|
| 1 | Махалля | Курпачи-батуты подбрасывают высоко, по газовым трубам можно бегать |
| 2 | Базар Чорсу | Ящики с дынями ломаются под ногами |
| 3 | Метро | Эскалаторы-конвейеры и поезда через пути |
| 4 | Анхор | Плавание: гребок кнопкой прыжка, течение несёт вправо |
| 5 | Телебашня | Вертикальный подъём, порывы ветра, лифт |
| 6 | Tashkent City | Тросы между крышами и босс Жадина-ака |

## Как получить APK

### Вариант 1 — GitHub (без установки чего-либо)
1. Создай новый репозиторий на github.com и загрузи туда содержимое этой папки.
2. Открой вкладку **Actions** → workflow **Build APK** запустится сам (или нажми *Run workflow*).
3. Через 3–5 минут скачай артефакт **Botir-apk** — внутри `app-release.apk`.

### Вариант 2 — Android Studio
1. File → Open → выбери папку `BotirGame`.
2. Дождись синхронизации Gradle.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s). Файл появится в `app/build/outputs/apk/`.

APK подписан debug-ключом, поэтому ставится сразу (разреши «Установка из неизвестных источников»). Для Google Play сделай свой ключ подписи.

## Структура кода
- `GameView.kt` — цикл 60 FPS, масштабирование пиксельного буфера, сенсорные кнопки.
- `Game.kt` — физика, механики, враги, пасхалки, босс, HUD.
- `Levels.kt` — 6 уровней (карты, пасхалки, декор).
- `Bg.kt` — параллакс-фоны локаций.
- `Sprites.kt` — Ботир, враги, NPC, предметы.
- `Menu.kt` — меню, выбор уровня, пауза, экраны победы.
- `Sound.kt` — синтез 8-битных звуков.
